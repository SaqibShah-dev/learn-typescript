# TypeScript Phase 3: React with TypeScript

Phase 3 introduces React development with TypeScript. You will learn how to apply TypeScript to components, props, state, events, refs, context, and custom hooks while building practical user interfaces.

## Overview

- Learn how to type React components and their props.
- Manage state safely with `useState` and persistent values with `useRef`.
- Handle browser events with accurate event types.
- Share application data with context and authentication providers.
- Create reusable custom hooks with clear TypeScript types.
- Practice these concepts in the `PracticeProject/todo-dashboard` application.

## What You Will Learn

| Topic | What to Learn |
| --- | --- |
| Typing Props | Define component props and make reusable components type-safe. |
| useState | Type state values, updates, and common state patterns. |
| useRef | Work with DOM elements and mutable values without triggering renders. |
| Event Types | Type events from inputs, forms, buttons, and other React elements. |
| Context | Share typed values across components without passing props through every level. |
| Custom Hooks | Extract reusable behavior while preserving type safety. |
| Forward Ref | Pass refs through components when a parent needs access to a child element. |
| Practice Project | Combine React and TypeScript concepts in a todo dashboard. |

## Prerequisites

Before starting Phase 3, review the TypeScript fundamentals from Phase 1 and the advanced type concepts from Phase 2. Basic familiarity with React components and JSX will also help.

## Suggested Learning Order

1. Start with `TypingProps` to understand how component inputs are typed.
2. Continue with `useState`, `useRef`, and `EventTypes`.
3. Study `Context` and `CustomHooks` to learn how to share and reuse typed logic.
4. Finish with `ForwardRef` and the `PracticeProject`.

## How to Use This Folder

Read each `.ts` file, experiment with the examples, and intentionally introduce type errors to see how TypeScript helps. Then explore the todo dashboard to see how the individual concepts work together in a React application.
